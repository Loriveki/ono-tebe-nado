# Ono Tebe Nado

## 🚀 О проекте
"Ono Tebe Nado" — это учебный проект, разработанный в рамках курса Яндекс.Практикума. Проект представляет собой одностраничный сайт аукционного дома, созданный по предоставленному макету в Figma.

## 🛠 Используемые технологии
🔹 HTML  
🔹 CSS

## 📦 Структура проекта
Проект состоит из следующих папок и файлов:

🔹 fonts/ — шрифты для сайта.  

🔹 images/ — изображения, включая фоновое и для карточек товаров.  

🔹 styles/ — стили проекта.    
    🔹 global.css — глобальные стили.  
    🔹 style.css — дополнительные стили для конкретных блоков и секций.  
    
🔹index.html — основной HTML-файл проекта.  



## 📥 Установка и запуск

Клонируйте репозиторий:
```
git clone https://github.com/Loriveki/ono-tebe-nado.git  
```
Откройте проект в вашем редакторе кода.  

Для работы с проектом достаточно просто открыть index.html в вашем браузере.
